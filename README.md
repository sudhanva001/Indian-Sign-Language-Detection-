# 🤟 Indian Sign Language Detection using Deep Learning

An AI-powered real-time Indian Sign Language (ISL) recognition system that detects hand gestures from a webcam using a Convolutional Neural Network (CNN) and converts recognized signs into speech. The project aims to improve communication between sign language users and people unfamiliar with sign language.

---

# 🚀 Features

* 🎥 **Real-Time Sign Detection**

  * Captures live hand gestures using a webcam and recognizes Indian Sign Language signs instantly.

* 🧠 **Deep Learning-Based Recognition**

  * Uses a Convolutional Neural Network (CNN) built with TensorFlow/Keras to accurately classify hand gestures.

* 🔊 **Sign-to-Speech Conversion**

  * Converts detected signs into spoken audio using text-to-speech technology for seamless communication.

* 📈 **High Recognition Accuracy**

  * Achieves approximately **90% accuracy** through image preprocessing and model optimization.

* ⚡ **Interactive and User-Friendly**

  * Provides instant predictions with a simple real-time interface.

---

# 📌 Problem Statement

Communication between deaf or hard-of-hearing individuals and people who do not understand sign language remains a challenge. This project addresses the problem by developing an AI-based system that recognizes Indian Sign Language gestures in real time and translates them into speech, making communication easier and more accessible.

---

* Detect Indian Sign Language gestures using computer vision.
* Classify gestures using a CNN-based deep learning model.

# 🔄 Working Process

1. Capture hand gestures through a webcam.
2. Preprocess the captured image to remove noise.
3. Feed the processed image into the trained CNN model.
4. Predict the corresponding Indian Sign Language gesture.
5. Display the detected sign and convert it into speech using text-to-speech.

---

# 📊 Model Performance

* **Model:** Convolutional Neural Network (CNN)
* **Recognition Accuracy:** ~90%
* **Framework:** TensorFlow/Keras
* **Input:** Live webcam images
* **Output:** Predicted sign with voice output
